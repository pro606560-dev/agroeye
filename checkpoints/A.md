## ทดสอบการใช้งาน
1. เปิดลิงก์ใน Chrome → เห็นหน้าแรก มีคำว่า "วันนี้จะดูแปลงไหน" และปุ่ม "ตรวจแปลงใหม่" → ✅/❌
2. กด "ตรวจแปลงใหม่" → เห็น "แปลงนี้ชื่ออะไร" และ "ขั้นที่ 1 จาก 6" → ✅/❌
3. พิมพ์ชื่อแปลงเล่น ๆ แล้วกด "ถัดไป" → เห็นรูปดิน 3 แบบ → ✅/❌
4. ไม่เลือกดิน แล้วกด "ถัดไป" → ขึ้นข้อความเตือนให้เลือกก่อน และยังอยู่หน้าเดิม → ✅/❌
5. เลือก "ดินเหนียว" กด "ถัดไป" พิมพ์ pH 5.5 กด "ถัดไป" → เห็นคำถามเรื่องน้ำขัง → ✅/❌
6. เลือก "น้ำขังนาน" กด "ถัดไป" ไปจนถึงหน้าสุดท้าย แล้วกด "ดูผล" → เห็นพืช 3 อันดับ พร้อมดาว คะแนน และเหตุผล → ✅/❌
7. กด "ดูวิธีปลูก" ของอันดับ 1 → เห็น "ทำไมได้คะแนนนี้" และคะแนนตรงกับการ์ด → ✅/❌
8. เลื่อนลงล่างสุดของหน้าพืช → เห็นแหล่งข้อมูล และชื่อแหล่งอ่านรู้เรื่อง ไม่ใช่รหัส → ✅/❌
9. กดปุ่มย้อนกลับ **ของมือถือ** (ไม่ใช่ของแอป) → กลับหน้าผล และกดต่อไปจะถอยทีละขั้น → ✅/❌
10. ที่หน้าผล กด "พืชอื่น ๆ" แล้วแตะชื่อ มะม่วง → แตะได้ง่าย เห็น "ยังไม่มีข้อมูล — สอบถามเกษตรอำเภอแม่ทะ" → ✅/❌
11. กลับหน้าแรก กด "ตรวจแปลงใหม่" กด "แปลง A" → ข้ามคำถามดินกับ pH ไปถามเรื่องน้ำขัง → ✅/❌
12. กด "แปลงของฉัน" → เห็น "หน้านี้กำลังสร้าง" พร้อมปุ่มกลับ (ยังไม่พัง ทำใน task 11) → ✅/❌
13. ดูทุกหน้า → ตัวอักษรอ่านสบายตาโดยไม่ต้องซูม และไม่ต้องเลื่อนซ้ายขวา → ✅/❌
14. ให้ผู้ใหญ่ที่บ้าน 1 คนลองตรวจแปลง 1 รอบ โดยไม่ช่วยบอก → จดว่าติดตรงไหน: ____________ → ✅/❌

## เรื่องที่ต้องให้ผู้ใช้ตัดสิน (ถามครูได้)
ตอบแค่เลือกทางในวงเล็บ ถ้ายังไม่แน่ใจ ตอบว่า "ใช้ตามที่แนะนำ" ได้

1. **พืชคะแนนต่ำยังขึ้นเป็น "แนะนำ" ได้** เช่น ข้าวเหนียว 40 คะแนน (แนะนำ: คงไว้ก่อน เพราะการ์ดบอกข้อเสียอยู่แล้ว หรือบอกตัวเลขคะแนนขั้นต่ำมา)
2. **ถ้าค่านอกช่วงเหมาะ และไม่มีข้อมูลช่วงที่ทนได้ แอปให้ 0** เช่น ขิงกับ pH (แนะนำ: คงไว้ตามไฟล์ข้อมูล แต่เขียนในรายงานว่าเป็นข้อจำกัด)
3. **พืชคะแนน 0 ไม่แนะนำแม้อยู่ใน 3 อันดับแรก และดาวต่ำสุดคือ 1 ดวง** (แนะนำ: คงไว้)
4. **ถ้ายังไม่มีข้อมูลอากาศ พืชคะแนน 100 อาจเสมอกันหลายชนิด** (แนะนำ: ดูใหม่หลัง task 10)

## เรื่องที่ต้องให้ครูหรือผู้รู้ช่วยดู
1. ประโยควิธีทดสอบดิน "พรมน้ำให้ดินชื้น แล้วคลึงเป็นเส้นบนฝ่ามือ" ถูกไหม (Claude เขียนเพิ่มเอง)
2. เกณฑ์คำ ดินเปรี้ยว/ปกติ/ด่าง (pH 6.6 และ 7.3) ยังไม่มีแหล่ง ใช้แค่แสดงคำ ไม่มีผลกับคะแนน
3. ชุดทดสอบดินของทีมบอก N/P/K เป็นตัวเลขหรือเป็นระดับ ต่ำ/กลาง/สูง ถ้าเป็นระดับต้องเปลี่ยนช่องกรอก
4. อายุข้าว 110–120 วันมาจากตารางนาปรัง แต่ กข6/หอมมะลิ ปลูกนาปี จริงอาจนานกว่า
5. อุณหภูมิของยางพารากับมะขามเป็นค่าเฉลี่ยทั้งปี แต่สูตรเทียบกับเดือนที่ปลูก ต้องตัดสินก่อน task 10
