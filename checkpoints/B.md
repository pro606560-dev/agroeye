# CHECKPOINT B — ตรวจช่วง 2 บนมือถือ OPPO A98

ทำทีละข้อใน Chrome บนมือถือ ใส่ ✅ หรือ ❌ ท้ายข้อ

ลิงก์: https://pro606560-dev.github.io/agroeye/

## เตรียมก่อนเริ่ม
- ถ้าเคยเปิดลิงก์นี้ในมือถือมาก่อน ให้เปิดลิงก์ 1 ครั้งแล้วปิด แล้วเปิดใหม่อีกครั้ง (ให้เครื่องโหลดเวอร์ชันใหม่) ถ้าเห็นแถบล่างจอ "มีเวอร์ชันใหม่ แตะเพื่ออัปเดต" ให้แตะ

## ติดตั้งแอปและใช้แบบไม่มีเน็ต
1. เปิดลิงก์ใน Chrome → กดปุ่ม ⋮ มุมขวาบน → "เพิ่มลงในหน้าจอหลัก" หรือ "ติดตั้งแอป" → มีไอคอน AgroEye (ต้นกล้าบนชั้นดิน พื้นน้ำเงิน) บนหน้าจอ → ✅/❌
2. แตะไอคอนบนหน้าจอ → แอปเปิดเต็มจอ ไม่มีแถบที่อยู่เว็บของ Chrome ด้านบน → ✅/❌
3. ตรวจแปลงใหม่ 1 แปลง ตั้งชื่อ "ทดสอบ B" กรอกจนจบ กด "ดูผล" แล้วกด "บันทึกแปลงนี้" → เห็นกล่องเขียว "บันทึกแปลงนี้แล้ว" → ✅/❌
4. **เปิดโหมดเครื่องบิน** (ปิด Wi-Fi และเน็ตมือถือ) ปัดปิดแอป AgroEye ออกจากรายการแอปที่เปิดอยู่ → ✅/❌
5. แตะไอคอน AgroEye อีกครั้ง → หน้าแรกเปิดได้ ไม่มีข้อความ error (กล่องอากาศวันนี้หายไปได้ ถือว่าถูก) → ✅/❌
6. กด "ตรวจแปลงใหม่" กรอกจนจบ กด "ดูผล" → เห็นพืช 3 อันดับ พร้อมคะแนนและเหตุผล → ✅/❌
7. กลับหน้าแรก กด "แปลงของฉัน" → เห็นแปลง "ทดสอบ B" พร้อมวันที่ → ✅/❌
8. กลับหน้าแรก กด "ปฏิทินปลูก" → เลื่อนไปที่เดือนนี้เอง มีกรอบหนาและป้าย "เดือนนี้" → ✅/❌
9. ในปฏิทิน แตะชื่อพืชใดก็ได้ → เปิดหน้าวิธีปลูกได้ แม้ไม่มีเน็ต → ✅/❌
10. ปิดโหมดเครื่องบิน เปิดแอปใหม่ → กล่อง "อากาศวันนี้ที่แม่ทะ" กลับมา (อาจใช้เวลาหลายวินาที) → ✅/❌

## แปลงของฉัน (task 11)
11. เปิดแปลง "ทดสอบ B" → กด "ลบแปลงนี้" → ขึ้นหน้าต่างถาม → กด "ไม่ลบ เก็บไว้" → แปลงยังอยู่ → ✅/❌
12. เปิดแปลง "ทดสอบ B" → กด "แก้ข้อมูล" → เปลี่ยนดินเป็นแบบอื่น → "ดูผล" → "บันทึกเป็นรอบใหม่ของแปลงนี้" → เห็นตาราง "เทียบกับครั้งก่อน" → ✅/❌

## ภาพรวม
13. ดูหน้าแปลงของฉันและปฏิทินปลูก → ตัวอักษรอ่านได้ไม่ต้องซูม ไม่ต้องเลื่อนซ้ายขวา ปุ่มแตะง่าย → ✅/❌
14. ให้ผู้ใหญ่ที่บ้าน 1 คนลองเปิดปฏิทินแล้วบอกว่าเดือนนี้ปลูกอะไรได้ โดยไม่ช่วยบอก → จดว่าติดตรงไหน: ____________ → ✅/❌

## เรื่องที่ควรรู้
- ข้อมูลแปลงเก็บในเครื่องมือถือเครื่องนั้นเท่านั้น ถ้าล้างข้อมูลของ Chrome แปลงที่บันทึกจะหาย
- ม.ค. ก.พ. ก.ย. ไม่มีพืชที่เริ่มปลูก เพราะในไฟล์ข้อมูลยังไม่มี ไม่ใช่แอปพัง
- พืช 7 ชนิดยังไม่มีข้อมูลเดือนปลูก แอปจึงแนะนำให้ถามเกษตรอำเภอแม่ทะ
