**อย่าลบไอคอนเดิม** รอบนี้ต้องดูว่าแปลงที่บันทึกไว้ก่อนอัปเดตยังอยู่

1. เปิดแอปจากไอคอนเดิม → ถ้าเห็นแถบ "มีเวอร์ชันใหม่" ให้แตะ → "ตั้งค่า" เลื่อนลงล่างสุด เห็น "AgroEye เวอร์ชัน 1.2" (ถ้ายังเห็น 1.1 ให้ปิดแอปแล้วเปิดใหม่ 1–2 ครั้ง) → ✅/❌
2. หน้าแรก → "แปลงของฉัน" → แปลงที่เคยบันทึกไว้ก่อนอัปเดต (เช่น "ทดสอบ C") ยังอยู่ครบ แตะเข้าไปเห็นผลเดิม → ✅/❌ (ถ้าไม่เคยบันทึกแปลงไว้ ให้เขียนว่า "ไม่มีแปลงเก่า")
3. ในหน้าแปลงนั้น เลื่อนลงถึง "บันทึกรอบปลูก" → แตะ "เพิ่มรอบปลูก" → แตะ "บันทึกรอบปลูก" ทันทีโดยไม่เลือกอะไร → เห็นกรอบ "ยังบันทึกไม่ได้ เลือกพืชที่ปลูกก่อน" → ✅/❌
4. เลือกพืช "ข้าวเหนียว กข6" ใส่วันที่ปลูก วันที่เก็บเกี่ยว และหมายเหตุ "ทดสอบ D" → แตะ "บันทึกรอบปลูก" → เห็น "บันทึกรอบปลูกแล้ว" และรายการข้าวพร้อมวันที่เป็น พ.ศ. → ✅/❌
5. ปิดแอปให้สนิท (ปัดทิ้ง) แล้วเปิดใหม่ → เข้าแปลงเดิม → รอบปลูก "ข้าวเหนียว กข6" ยังอยู่ → แตะ "ลบรอบนี้" → ต้องมีปุ่มถามซ้ำ "ลบรอบปลูกนี้" / "ไม่ลบ" → แตะ "ลบรอบปลูกนี้" → รอบนั้นหายไป แต่แปลงยังอยู่ → ✅/❌
6. หน้าแรก → "ตรวจแปลงใหม่" ตั้งชื่อ "ทดสอบ D" ตอบจนถึงหน้าผล → แตะ "บันทึกผลเป็นรูป" → เห็นข้อความ "บันทึกรูปแล้ว" → เปิดแอปรูปภาพหรือแอปไฟล์ (หัวข้อดาวน์โหลด) เจอไฟล์ `agroeye-result-....png` → ✅/❌
7. เปิดรูปนั้นดู → ตัวหนังสืออ่านได้โดยไม่ต้องซูม มีชื่อแปลง "ทดสอบ D" วันที่วันนี้ พืช 3 อันดับพร้อมคะแนน และข้อความ "ผลจากสูตรคะแนนของ AgroEye ใช้ประกอบการตัดสินใจเท่านั้น" ไม่มีพิกัดหรือชื่อคน → ✅/❌
8. ปิดเน็ต (โหมดเครื่องบิน) → เปิดแอป → "แปลงของฉัน" → เพิ่มรอบปลูกได้ และกด "บันทึกผลเป็นรูป" ในหน้าผลได้ → เปิดเน็ตกลับ → ✅/❌
