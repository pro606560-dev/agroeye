# CHECKPOINT C (จบงาน) — ตรวจแอปเวอร์ชัน 1.0 บนมือถือ OPPO A98

ทำทีละข้อใน Chrome บนมือถือ ใส่ ✅ หรือ ❌ ท้ายข้อ ถ้า ❌ ให้จดสั้น ๆ ว่าเห็นอะไร

ลิงก์: https://pro606560-dev.github.io/agroeye/

## เตรียมก่อนเริ่ม
- **ลบไอคอน AgroEye เดิมออกจากหน้าจอก่อน** (กดค้างที่ไอคอน → ถอนการติดตั้ง/ลบ)
- เตรียมรหัส AI (Gemini API key) ที่ผู้ใหญ่สร้างจาก aistudio.google.com ไว้ในมือถือ **ห้ามพิมพ์รหัสในแชต**

## ติดตั้งใหม่และใช้ครบทุกหน้า
1. เปิดลิงก์ใน Chrome → ⋮ → "เพิ่มลงในหน้าจอหลัก" หรือ "ติดตั้งแอป" → แตะไอคอนใหม่ → แอปเปิดเต็มจอ → ✅/❌
2. แตะ "ตั้งค่า" → เลื่อนลงล่างสุด → เห็น "AgroEye เวอร์ชัน 1.0" (ถ้ายังเห็น 0.16 ให้ปิดแอปแล้วเปิดใหม่ หรือแตะแถบ "มีเวอร์ชันใหม่") → ✅/❌
3. หน้าแรก กด "ตรวจแปลงใหม่" ตั้งชื่อ "ทดสอบ C" ตอบทุกหน้าจนกด "ดูผล" → เห็นพืช 3 อันดับ มีดาว คะแนน เหตุผล และความมั่นใจ → ✅/❌
4. ในหน้าผล กด "ฟังคำแนะนำ" (ถ้ามีปุ่ม) → ได้ยินเสียงภาษาไทยอ่านผล → ✅/❌ (ถ้าไม่มีปุ่มเลย ให้เขียนว่า "ไม่มีปุ่ม")
5. กด "บันทึกแปลงนี้" → เห็น "บันทึกแปลงนี้แล้ว" → กด "ดูวิธีปลูก" ของอันดับ 1 → เห็นวิธีดูแล ความเสี่ยง และแหล่งข้อมูล → ✅/❌
6. กลับหน้าแรก → "แปลงของฉัน" → เห็น "ทดสอบ C" พร้อมวันที่วันนี้ → แตะเข้าไปแล้วเห็นผลเดิม → ✅/❌
7. กลับหน้าแรก → "ปฏิทินปลูก" → เลื่อนไปเดือนนี้เอง ตัวเลข "องศา / ฝน" อ่านได้ชัด ไม่เล็กเกินไป → ✅/❌
8. "ตั้งค่า" → ตัวเลือกขนาดตัวอักษร: คำว่า "ใหญ่" กับ "ใหญ่มาก" ตัวใหญ่ขึ้นตามลำดับ → เลือก "ใหญ่มาก" → ทุกหน้าตัวใหญ่ขึ้น ไม่มีหน้าไหนต้องเลื่อนซ้ายขวา → เลือกกลับเป็น "ปกติ" → ✅/❌
9. "ตั้งค่า" → "ดูผลพิสูจน์สมมติฐาน" → เห็นตาราง กราฟ → กด "จับเวลา 10 รอบ" → **จดค่าเฉลี่ยที่ได้บน OPPO ไว้ใส่รายงาน:** ______ มิลลิวินาที (ต้องน้อยกว่า 1,000) → ✅/❌

## ไม่มีเน็ต
10. เปิด **โหมดเครื่องบิน** → ปัดปิดแอป → แตะไอคอนเปิดใหม่ → "ตรวจแปลงใหม่" กรอกจนจบ → ยังเห็นพืช 3 อันดับ → ✅/❌
11. ยังอยู่ในโหมดเครื่องบิน → ปฏิทินปลูก และหน้าพิสูจน์สมมติฐาน เปิดได้ → ปิดโหมดเครื่องบิน → ✅/❌

## AI ช่วยอธิบาย (ยังไม่เคยทดสอบกับรหัสจริง)
12. "ตั้งค่า" → วางรหัสในช่อง "รหัส AI" → กด "บันทึกรหัส" → เห็นข้อความว่าบันทึกแล้ว → ✅/❌
13. ตรวจแปลงใหม่จนเห็นผล → "ดูวิธีปลูก" → เลื่อนลงล่าง → เห็นกล่อง "คำอธิบายสำหรับแปลงนี้" มีป้าย "คำอธิบายจาก AI อาจผิดพลาดได้" → ✅/❌
14. อ่านคำอธิบายจาก AI: ภาษาง่ายไหม สั้นไหม (ไม่เกิน 5 บรรทัด) และ**ไม่ได้แนะนำยาหรือสารเคมีที่ไม่มีในหน้าวิธีปลูก** → ✅/❌ (ถ้า ❌ จดว่า AI พูดอะไรเกินมา)

## ของสำหรับรายงาน (เปิดบนคอม)
