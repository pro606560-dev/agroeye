# คู่มือเซนเซอร์ ESP32 สำหรับ AgroEye (task 18)

บอร์ดวัด 3 ค่า แล้วโชว์เป็นข้อความสั้นบนหน้าเว็บของบอร์ดเอง เช่น `M=45;T=29.5;L=62`
คัดลอกข้อความนี้ไปวางในแอป AgroEye ได้เลย ไม่ต้องมีเน็ต ไม่ต้องมี token

| ตัวย่อ | ค่า | มาจาก | แอปใช้ทำอะไร |
| --- | --- | --- | --- |
| M | ความชื้นดิน (%) | เซนเซอร์ Capacitive (แผ่นดำ) | เติมช่อง "ความชื้นดิน (%)" ให้ และเก็บในประวัติแปลง |
| T | อุณหภูมิอากาศตอนวัด (องศา) | DHT11 / DHT22 | เก็บในประวัติแปลง |
| L | ความสว่างเทียบ 0–100 | LDR | เก็บในประวัติแปลง |

**ค่าจากเซนเซอร์ยังไม่ใช้คิดคะแนน** เพราะ
- อุณหภูมิในสูตรคะแนนเป็นค่าเฉลี่ยรายเดือนจากข้อมูลภูมิอากาศ ค่าที่วัดครั้งเดียวในวันเดียวแทนกันไม่ได้
- แสงในสูตรเป็นแค่ "แดดจัด" หรือ "ร่มรำไร" ยังไม่มีแหล่งอ้างอิงว่า LDR วัดได้กี่ % ถึงจะเรียกว่าแดดจัด จึงยังให้ผู้ใช้เลือกเองเหมือนเดิม
- ความชื้นดินเดิมก็ยังไม่ใช้คิดคะแนนอยู่แล้ว (SPEC ข้อ 4.1)

## 1. ของที่ต้องมี
- บอร์ด ESP32 (แบบ DevKit 30 หรือ 38 ขา) + สาย USB ที่ส่งข้อมูลได้ (ไม่ใช่สายชาร์จอย่างเดียว)
- เซนเซอร์ความชื้นดิน Capacitive (v1.2 หรือ v2.0)
- DHT22 (สีขาว) หรือ DHT11 (สีฟ้า)
- LDR แบบแผงวงจรเล็กที่มีขา AO (ถ้าเป็นตัว LDR เปล่า ต้องมีตัวต้านทาน 10kΩ เพิ่ม 1 ตัว)
- สายจัมเปอร์ และ breadboard

## 2. การต่อขา
**ใช้ไฟ 3V3 เท่านั้น ห้ามใช้ 5V (VIN)** เพราะขาอ่านค่าของ ESP32 รับได้แค่ราว 3.3V ถ้าเกินอาจทำให้บอร์ดเสีย

| เซนเซอร์ | ขาเซนเซอร์ | ต่อกับขา ESP32 |
| --- | --- | --- |
| ความชื้นดิน Capacitive | VCC | 3V3 |
| | GND | GND |
| | AOUT | GPIO 34 (D34) |
| LDR (แผงวงจร) | VCC | 3V3 |
| | GND | GND |
| | AO | GPIO 35 (D35) |
| | DO | ไม่ต้องต่อ |
| DHT22 / DHT11 (แบบแผงวงจร 3 ขา) | + หรือ VCC | 3V3 |
| | − หรือ GND | GND |
| | OUT หรือ DATA | GPIO 4 (D4) |

- ถ้าเป็น DHT ตัวเปล่า 4 ขา: ขา 1 = 3V3, ขา 2 = DATA ต่อ GPIO 4 และต่อตัวต้านทาน 10kΩ จากขา 2 ไป 3V3, ขา 3 ไม่ต่อ, ขา 4 = GND
- ถ้าเป็น LDR ตัวเปล่า: ขาหนึ่งต่อ 3V3 อีกขาต่อ GPIO 35 แล้วต่อตัวต้านทาน 10kΩ จาก GPIO 35 ไป GND
- ทำไมต้อง GPIO 34 กับ 35: ขาอ่านค่ากลุ่ม ADC2 ใช้ไม่ได้ตอนบอร์ดเปิด Wi-Fi จึงเลือกขากลุ่ม ADC1 (32–39)
- เสียบเซนเซอร์ความชื้นดินลงดินแค่ถึงเส้นที่พิมพ์ไว้บนแผ่น อย่าให้ส่วนวงจรด้านบนโดนน้ำ

## 3. ติดตั้งโปรแกรม (ทำครั้งเดียว)
คอมเครื่องนี้มี Arduino IDE แล้ว แต่ยังไม่มีชุดบอร์ด ESP32 กับไลบรารี DHT
1. เปิด Arduino IDE → File → Preferences → ช่อง "Additional boards manager URLs" ใส่
   `https://espressif.github.io/arduino-esp32/package_esp32_index.json` → OK
2. ด้านซ้ายกดไอคอนบอร์ด (Boards Manager) → ค้นคำว่า `esp32` → ติดตั้ง **esp32 by Espressif Systems**
3. ด้านซ้ายกดไอคอนหนังสือ (Library Manager) → ค้น `DHT sensor library` → ติดตั้งของ **Adafruit** (ถ้าถามว่าจะติดตั้ง Adafruit Unified Sensor ด้วยไหม ให้กด Install All)

## 4. อัปโหลดโค้ดลงบอร์ด
1. File → Open → เปิดไฟล์ `esp32/agroeye-sensor/agroeye-sensor.ino` ในโฟลเดอร์ AgroEye
2. ถ้าใช้ DHT11 แก้บรรทัด `#define DHT_TYPE DHT22` เป็น `#define DHT_TYPE DHT11`
3. ควรเปลี่ยนรหัส Wi-Fi ในบรรทัด `WIFI_PASSWORD` เป็นของทีมเอง (อย่างน้อย 8 ตัว)
4. เสียบสาย USB → Tools → Board → esp32 → **ESP32 Dev Module** → Tools → Port → เลือก COM ที่ขึ้นมาใหม่
5. กดปุ่มลูกศร (Upload) ถ้าค้างที่ "Connecting..." ให้กดปุ่ม BOOT บนบอร์ดค้างไว้จนเริ่มอัปโหลด

## 5. เทียบค่า (calibrate) — สำคัญ ต้องทำเองก่อนใช้จริง
ค่าดิบของเซนเซอร์แต่ละตัวไม่เท่ากัน ต้องวัดจุดต่ำสุดและสูงสุดของตัวเองก่อน แล้วแก้ตัวเลขในโค้ด

1. อัปโหลดโค้ดแล้วเปิด Tools → Serial Monitor ตั้งความเร็ว **115200** จะเห็นบรรทัด `ดินดิบ=2950 แสงดิบ=1800 → M=...` ทุก 2 วินาที (หรือดูค่าดิบที่ท้ายหน้าเว็บของบอร์ดก็ได้)
2. **ความชื้นดิน**
   - ดินแห้ง: เช็ดเซนเซอร์ให้แห้ง ถือไว้ในอากาศ (หรือเสียบในดินที่ตากแห้งสนิท) จดค่า `ดินดิบ` → ใส่ใน `SOIL_RAW_DRY`
   - ดินเปียก: เสียบเซนเซอร์ในแก้วน้ำแค่ถึงเส้น (หรือดินที่รดน้ำจนชุ่มโชก) จดค่า → ใส่ใน `SOIL_RAW_WET`
   - ปกติค่าดินแห้งจะมากกว่าค่าดินเปียก (ดินยิ่งเปียก ตัวเลขยิ่งน้อย)
3. **แสง**
   - เอามือปิด LDR มิด จดค่า `แสงดิบ` → ใส่ใน `LIGHT_RAW_DARK`
   - ถือ LDR ตากแดดจัดกลางวัน จดค่า → ใส่ใน `LIGHT_RAW_BRIGHT`
4. อัปโหลดโค้ดใหม่อีกครั้ง แล้วลองวัด: ในอากาศควรได้ M ใกล้ 0 ในน้ำควรได้ M ใกล้ 100
5. จดค่าทั้ง 4 ตัวกับวันที่เทียบไว้ในสมุดโครงงาน (ใช้เขียนในรายงานบทวิธีดำเนินงานได้)

หมายเหตุ: ความชื้น % นี้เป็นค่า "เทียบระหว่างแห้งสนิทถึงเปียกโชก" ไม่ใช่ความชื้นดินแบบวัดในห้องแล็บ

## 6. วิธีใช้กับมือถือ
1. เปิดแอป AgroEye ในมือถือ 1 ครั้งตอนมีเน็ตก่อน (แอปจะจำไฟล์ไว้ใช้ออฟไลน์)
2. เสียบไฟบอร์ด ESP32 (สาย USB กับพาวเวอร์แบงก์ได้) และเสียบเซนเซอร์ลงดินในแปลง
3. มือถือ → ตั้งค่า → Wi-Fi → ต่อ **AgroEye-Sensor** ใส่รหัส ถ้ามือถือเตือนว่า "ไม่มีอินเทอร์เน็ต" ให้เลือก **ใช้ต่อ / เชื่อมต่อต่อไป**
4. เปิด Chrome พิมพ์ `192.168.4.1` → กด **คัดลอก** (อยากวัดใหม่กด "วัดใหม่")
5. เปิดแอป AgroEye → ตรวจแปลงใหม่ → ถึงขั้น "มีข้อมูลเพิ่มเติมไหม" → แตะ "วางค่าจากเซนเซอร์ (ESP32)" → กดค้างที่ช่องแล้วเลือก **วาง** (หรือกด "วางจากที่คัดลอกไว้") → กด **ใช้ค่านี้**
6. ช่องความชื้นดินจะเติมให้เอง กด "ดูผล" แล้ว "บันทึก" ตามปกติ ค่าทั้ง 3 จะไปอยู่ในหน้า "แปลงของฉัน"
7. เสร็จแล้วปิด Wi-Fi AgroEye-Sensor มือถือจะกลับไปใช้เน็ตปกติ

## 7. แก้ปัญหา
| อาการ | ลองทำ |
| --- | --- |
| ไม่เห็น Wi-Fi AgroEye-Sensor | ดูว่าอัปโหลดสำเร็จไหม กดปุ่ม EN (รีเซ็ต) บนบอร์ด รอ 5 วินาที |
| เปิด 192.168.4.1 ไม่ขึ้น | มือถืออาจสลับกลับไปใช้เน็ตมือถือ ให้ปิดข้อมูลมือถือชั่วคราว |
| ไม่มี T ในข้อความ (แอปบอกว่า "อุณหภูมิ ไม่มีค่า") | DHT อ่านไม่ได้: ตรวจสาย ขา DATA ต้องอยู่ GPIO 4 และเลือกรุ่น DHT11/DHT22 ในโค้ดให้ถูก |
| M เป็น 0 หรือ 100 ตลอด | ยังไม่ได้เทียบค่า หรือสาย AOUT หลุด ดูค่าดิบใน Serial Monitor |
| L ไม่เปลี่ยนเลย | ตรวจว่าใช้ขา AO (ไม่ใช่ DO) ต่อเข้า GPIO 35 |
| แอปบอก "อ่านค่าไม่ออก" | คัดลอกไม่ครบ ข้อความต้องหน้าตาแบบ `M=45;T=29;L=62` |
