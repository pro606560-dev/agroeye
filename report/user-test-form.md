# แบบสอบถามความพึงพอใจต่อแอป AgroEye

สำหรับเกษตรกรในอำเภอแม่ทะ 5–10 คน ให้ผู้ถาม (นักเรียน) อ่านให้ฟังแล้วกรอกแทน
ใช้ต่อจากภาคผนวก ข ในรายงาน (Claude Code ไม่เห็นเนื้อหาภาคผนวก ข ให้ผู้ใช้ตรวจว่าข้อไหนซ้ำ แล้วรวมเป็นชุดเดียว)

## ก่อนเริ่ม (ผู้ถามอ่านให้ฟัง)
"แอปนี้ช่วยแนะนำพืชที่เหมาะกับแปลงของลุง/ป้า/น้า ขอให้ลองใช้ประมาณ 10 นาที แล้วตอบคำถามสั้น ๆ ไม่มีถูกหรือผิด
ไม่บันทึกชื่อจริง และไม่ถามที่อยู่บ้าน ถ้าไม่อยากตอบข้อไหน ข้ามได้"

## วิธีสรุปผล (สำหรับนักเรียน)
1. หาค่าเฉลี่ยแต่ละข้อ = ผลรวมคะแนน ÷ จำนวนคนที่ตอบข้อนั้น (คนที่ข้ามไม่นับ)
2. แปลความหมายค่าเฉลี่ย (เกณฑ์ช่วงละ 0.8 ซึ่งใช้กันทั่วไปในงานวิจัยไทย ให้ตรวจกับครูว่าใช้เกณฑ์นี้ได้):
   - 4.21–5.00 = มากที่สุด
   - 3.41–4.20 = มาก
   - 2.61–3.40 = ปานกลาง
   - 1.81–2.60 = น้อย
   - 1.00–1.80 = น้อยที่สุด
3. ส่วนที่ 2 นับว่ากี่คนทำงานแต่ละข้อได้เอง แล้วคิดเป็นร้อยละ
4. ข้อที่ได้ต่ำกว่า 3.41 หรือมีคนทำเองไม่ได้หลายคน ให้เขียนเป็น "สิ่งที่ควรปรับปรุง" ในรายงาน
5. ผู้ตอบ 5–10 คนเป็นกลุ่มเล็ก ให้เขียนในข้อจำกัดว่าผลนี้ใช้สรุปทั้งอำเภอไม่ได้
