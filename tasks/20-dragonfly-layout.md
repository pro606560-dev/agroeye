# Task 20 (เสริม ผู้ใช้สั่งเมื่อ 9 พ.ย. 2569) — ปรับหน้าตาตามแบบที่ดีจาก Dragonfly ช่วงที่ 1

## เป้าหมาย
ปรับการจัดหน้า 3 จุดให้อ่านง่ายและกดง่ายขึ้นสำหรับผู้สูงอายุ โดยใช้แบบที่ดีจากแอป Dragonfly (GISTDA)
**แก้เฉพาะหน้าตา** ไม่เปลี่ยนสูตรคะแนน ข้อมูล หรือการเก็บข้อมูล และไม่เพิ่มบริการออนไลน์

## ต้องทำเสร็จก่อน
Task 19 ข้อ D เสร็จแล้ว และ tests.html ผ่านทั้งหมด (เริ่มต้น 202/202 และข้อสอบเฉลย 11/11)

## ขั้นตอน
1. **การ์ดเมนูหน้าแรก:** เปลี่ยนลิงก์ขีดเส้นใต้ "ปฏิทินปลูก" กับ "ตั้งค่า" เป็นการ์ดแถวยาว มีไอคอน ชื่อ คำอธิบายสั้น และลูกศร › (แบบหน้า "เมนูอื่นๆ" ของ Dragonfly) ไอคอนเป็น SVG ฝังในโค้ด จึงไม่ต้องเพิ่มไฟล์ที่ต้องแคช
2. **สรุปแปลงแบบแถว "หัวข้อ / คำ":** หน้าผลลัพธ์และหน้าแปลงเดียว เปลี่ยนประโยคที่คั่นด้วย · เป็นแถว ดิน / ความเปรี้ยวของดิน / หลังฝนตกหนัก / เดือนที่ปลูก ค่าที่ไม่รู้ให้เขียนว่า "ไม่ทราบ"
3. **การ์ดรอบปลูก:** รายการรอบปลูกในหน้าแปลงเดียวใช้แถว "หัวข้อ / คำ" แบบเดียวกัน (วันที่ปลูก / วันที่เก็บเกี่ยว / หมายเหตุ)
