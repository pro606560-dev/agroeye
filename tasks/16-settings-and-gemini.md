# Task 16 — หน้าตั้งค่า + Gemini อธิบาย [ใช้ reviewer]

## เป้าหมาย
ผู้ใช้ปรับแอปได้ และถ้ามี key ก็ได้คำอธิบายเฉพาะแปลงจาก AI โดยที่แอปไม่ต้องพึ่ง AI

## ต้องทำเสร็จก่อน
15

## ขั้นตอน
1. `js/views/settings.js`: ขนาดตัวอักษร 3 ระดับ, เปิด/ปิดเสียง, ความเร็วเสียง, ช่อง Gemini API key (ซ่อนตัวอักษร มีปุ่มแสดง/ซ่อน และปุ่มลบ key), ปุ่มล้างประวัติ (มีหน้าต่างยืนยัน), ลิงก์ไปหน้าพิสูจน์สมมติฐาน, ส่วน "เกี่ยวกับแอป" ที่มีเวอร์ชันและรายการแหล่งข้อมูล
2. อ่านเอกสาร Gemini API ปัจจุบันของ Google เพื่อดูชื่อรุ่น Flash-Lite ที่ใช้ฟรีได้และรูปแบบการเรียก **ห้ามเดาชื่อรุ่น** แล้วจดชื่อรุ่นกับวันที่ตรวจลง PROGRESS.md
3. `js/ai.js`: `explain(plot, cropResult)` ส่งเฉพาะ: ประเภทดิน, pH, น้ำขัง, เดือน, ชื่อพืช, คะแนนแยกปัจจัย และข้อความ care/risks จาก crops.json **ห้ามส่งชื่อแปลงหรือพิกัด**
4. prompt ที่ส่งให้ Gemini ต้องบอกให้
   - ตอบภาษาไทยง่าย ๆ ไม่เกิน 5 บรรทัด สำหรับเกษตรกรสูงอายุ
   - ใช้เฉพาะข้อมูลที่ส่งไป ห้ามแนะนำชื่อสารเคมีหรืออัตราการใช้ที่ไม่ได้อยู่ในข้อมูล
   - ถ้าข้อมูลไม่พอ ให้บอกให้ปรึกษาเกษตรอำเภอ
5. timeout 15 วินาที ถ้าล้มเหลว (ไม่มีเน็ต, key ผิด, เกินโควตา) ให้แสดงข้อความสั้นที่เข้าใจง่าย แล้วใช้ข้อความจาก crops.json แทน
6. เก็บคำตอบไว้ใน localStorage ตามชุดข้อมูลเดียวกัน จะได้ไม่เรียกซ้ำ (ประหยัดโควตา)
7. แสดงป้ายเล็ก "คำอธิบายจาก AI อาจผิดพลาดได้"
8. **ทดสอบ AI:** ขอให้ผู้ใช้กรอก key เองในหน้าตั้งค่าบนเบราว์เซอร์ **ห้ามให้ผู้ใช้พิมพ์ key ในแชต** ถ้ายังไม่มี key ให้ทดสอบเฉพาะกรณีล้มเหลว แล้วจดว่าค้างทดสอบไว้

## Skill ที่ใช้
- `design:ux-copy`: ข้อความในหน้าตั้งค่า และข้อความตอน AI ใช้ไม่ได้
- `design:accessibility-review`: ตรวจหน้าตั้งค่า

ถ้าไม่มี skill นี้ในรายชื่อ ให้ทำงานต่อตามหลักใน `docs/SPEC.md` แล้วจดใน PROGRESS.md ว่าไม่ได้ใช้
