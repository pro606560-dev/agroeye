# Task 18 (ทำเมื่อผู้ใช้สั่งเท่านั้น) — รับค่าจากเซนเซอร์ ESP32

## เป้าหมาย
ใช้ค่าความชื้นดิน แสง และอุณหภูมิจากเซนเซอร์จริงแทนการกรอกเอง

## ต้องทำเสร็จก่อน
CHECKPOINT C ผ่านแล้ว และผู้ใช้มีบอร์ด ESP32 กับเซนเซอร์จริง

## แนวทาง (ถามผู้ใช้เลือกก่อนเริ่ม)
- **ทางง่าย (แนะนำ):** ESP32 แสดงค่าเป็นข้อความสั้น (เช่น `M=45;T=29;L=800`) ผ่านหน้าเว็บเล็ก ๆ ของบอร์ดเอง ผู้ใช้คัดลอกไปวางในช่อง "วางค่าจากเซนเซอร์" ของแอป
- **ทางกลาง:** ใช้ Blynk ตามที่เขียนไว้ในรายงาน แล้วให้แอปอ่านค่าผ่าน API ของ Blynk (ต้องตรวจเรื่อง token และ CORS)

## ขั้นตอน
1. อ่านโค้ด Tinkercad เดิมของผู้ใช้ (ขอไฟล์จากผู้ใช้)
2. เขียนโค้ด Arduino สำหรับ ESP32 พร้อมอธิบายการต่อขาเป็นภาษาไทย
3. เพิ่มช่องรับค่าเซนเซอร์ในหน้ากรอกข้อมูล
4. ความชื้นดินจากเซนเซอร์ต้องแปลงเป็น % ด้วยการเทียบค่า (calibrate) กับดินแห้งและดินเปียก อธิบายวิธีให้ผู้ใช้ทำเอง
