# Task 08 — หน้ารายละเอียดพืช

## เป้าหมาย
บอกวิธีปลูก ดูแล และความเสี่ยงจากข้อมูลที่มีแหล่งจริงเท่านั้น

## ต้องทำเสร็จก่อน
07

## ขั้นตอน
1. `js/views/crop.js` แสดงข้อมูลจาก crops.json: เดือนที่ปลูกได้ (เป็นแถบ 12 เดือน), อายุเก็บเกี่ยว, การดูแล, ความเสี่ยงและวิธีแก้, หลักฐานว่าปลูกในแม่ทะ
2. ช่องที่เป็น null หรือรายการว่าง ให้แสดงว่า "ยังไม่มีข้อมูล — สอบถามเกษตรอำเภอแม่ทะ" ห้ามเติมข้อความเอง
3. ถ้าเข้ามาจากหน้าผลลัพธ์ ให้แสดงตารางเล็ก "ทำไมได้คะแนนนี้" จาก `factors` (ปัจจัย, ค่าของแปลง, ช่วงที่พืชต้องการ, ผ่าน/พอได้/ไม่ผ่าน)
4. ส่วน "แหล่งข้อมูล" แสดงชื่อแหล่งจากรหัส source (สร้าง `data/sources.json` จาก SOURCES.md ได้ แต่ต้องตรงกันทุกตัว)
5. เว้นที่ไว้สำหรับคำอธิบายจาก AI (ใช้ใน task 16) และปุ่มฟังเสียง (ใช้ใน task 15)

## Skill ที่ใช้
- `design:ux-copy`: ข้อความ "ยังไม่มีข้อมูล" และหัวข้อแต่ละส่วน

ถ้าไม่มี skill นี้ในรายชื่อ ให้ทำงานต่อตามหลักใน `docs/SPEC.md` แล้วจดใน PROGRESS.md ว่าไม่ได้ใช้

## เกณฑ์ผ่าน
- [ ] เปิดหน้ารายละเอียดได้ครบทั้ง 12 พืช โดยไม่มี error
- [ ] ทุกข้อความแนะนำที่แสดงมีแหล่งกำกับ
- [ ] พืชที่ข้อมูลไม่ครบ (เช่น มะม่วง) แสดง "ยังไม่มีข้อมูล" อย่างสุภาพ
