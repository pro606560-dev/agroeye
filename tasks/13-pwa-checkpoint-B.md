# Task 13 — ใช้ออฟไลน์ได้ (PWA) — CHECKPOINT B [ใช้ reviewer]

## เป้าหมาย
ติดตั้งแอปเป็นไอคอนบนมือถือได้ และใช้แบบไม่มีเน็ตได้

## ต้องทำเสร็จก่อน
11, 12

## ขั้นตอน
1. `manifest.webmanifest`: ชื่อ AgroEye, ชื่อสั้น, ไอคอน 192 และ 512 px (ทำเอง), สีธีม, `start_url` และ `scope` แบบ relative
2. `sw.js`: แคชไฟล์ทั้งหมดของแอป (html, css, js, data, assets, lib) ใช้กลยุทธ์ cache-first สำหรับไฟล์แอป และ network-only สำหรับ Open-Meteo กับ Gemini ใส่เลขเวอร์ชันแคช ถ้าเปลี่ยนเวอร์ชัน ให้ลบแคชเก่า
3. ลงทะเบียน service worker ใน `app.js` เฉพาะตอนที่เบราว์เซอร์รองรับ
4. เมื่อมีเวอร์ชันใหม่ ให้แสดงแถบเล็ก "มีเวอร์ชันใหม่ แตะเพื่ออัปเดต"
5. push ขึ้น GitHub Pages แล้วตรวจด้วยเครื่องมือของ Chrome ว่าแคชครบ
6. ตรวจ `design:accessibility-review` กับหน้าใหม่ (แปลงของฉัน, ปฏิทิน)
7. อัปเดต PROGRESS.md แล้วหยุด

## Skill ที่ใช้
- `design:accessibility-review`: ตรวจหน้าแปลงของฉันกับปฏิทินปลูก
- `design:ux-copy`: ข้อความแถบ "มีเวอร์ชันใหม่"

ถ้าไม่มี skill นี้ในรายชื่อ ให้ทำงานต่อตามหลักใน `docs/SPEC.md` แล้วจดใน PROGRESS.md ว่าไม่ได้ใช้

## รายการให้ผู้ใช้ทดสอบบน OPPO
1. เปิดลิงก์ แล้วกด "เพิ่มลงในหน้าจอหลัก" หรือ "ติดตั้งแอป" ใน Chrome
2. เปิดจากไอคอนบนหน้าจอ
3. ตรวจแปลงใหม่ 1 แปลง แล้วบันทึก
4. **เปิดโหมดเครื่องบิน** ปิดแอปแล้วเปิดใหม่จากไอคอน
5. ยังตรวจแปลงใหม่และเห็นผลได้ หน้าแรกไม่แสดง error เรื่องอากาศ
6. แปลงที่บันทึกไว้ยังอยู่
7. ปฏิทินปลูกเปิดได้และเดือนนี้ถูกไฮไลต์
