# Task 10 — สภาพอากาศ (Open-Meteo)

## เป้าหมาย
ใช้อุณหภูมิและฝนของแม่ทะในการให้คะแนน ทั้งตอนมีเน็ตและไม่มีเน็ต

## ต้องทำเสร็จก่อน
CHECKPOINT A ผ่านแล้ว

## ขั้นตอน
1. อ่านเอกสาร Open-Meteo ปัจจุบัน (https://open-meteo.com/) ก่อนเขียนโค้ด ห้ามเดารูปแบบ URL
2. **ดึงข้อมูลครั้งเดียวตอนพัฒนา:** ใช้ข้อมูลย้อนหลังของพิกัด 18.135, 99.513 อย่างน้อย 10 ปีเต็ม คำนวณ
   - อุณหภูมิเฉลี่ยรายเดือน 12 ค่า (°C)
   - ฝนรวมเฉลี่ยรายเดือน 12 ค่า และฝนรวมเฉลี่ยต่อปี (มม.)
   แล้วบันทึกเป็น `data/climate-maetha.json` พร้อมช่วงปีที่ใช้ วันที่ดึง และ `source: "OPEN-METEO"` (เก็บสคริปต์ที่ใช้คำนวณไว้ใน `tools/` ด้วย เพื่อให้ทำซ้ำได้)
3. `js/weather.js`:
   - `getClimate()` คืนค่าจาก `climate-maetha.json` (ใช้ได้เสมอ)
   - `getToday()` เรียกพยากรณ์วันนี้จาก Open-Meteo ตั้ง timeout 8 วินาที ถ้าไม่สำเร็จให้คืน null ไม่แสดง error ที่น่ากลัว
4. ต่อ `climate` เข้ากับ `rankCrops()`: อุณหภูมิใช้ค่าเฉลี่ยเดือนที่ผู้ใช้จะปลูก ส่วนฝนใช้ฝนรวมเฉลี่ยต่อปี
4.1 **อุณหภูมิตามชนิดพืช (ผู้ใช้ตัดสินหลัง CHECKPOINT A, ดู docs/SPEC.md ข้อ 4.1.1):**
   - `crops.json` มี `lifeForm` และ `tempBasis` แล้ว พืช `annual` (`growing_season_mean`) เทียบกับอุณหภูมิเฉลี่ยของเดือนที่อยู่ในแปลง ไม้ยืนต้น `perennial` (`annual_mean`: ยางพารา มะขาม ลำไย มะม่วง) เทียบกับอุณหภูมิเฉลี่ยทั้งปี
   - เพิ่มตัวกรองความหนาวใน `js/scoring.js`: ถ้าพืชมี `coldLimitC` (ตอนนี้มียางพารา [14, 15] และมะขาม [-3, -1]) และต่ำสุดเฉลี่ยของเดือนที่หนาวที่สุดต่ำกว่าช่วงนั้น ให้**ลด**คะแนนอุณหภูมิ ห้ามตัดเป็น 0 ค่าที่ลดต้องอยู่ใน `js/config.js` และถามผู้ใช้ก่อนเลือกตัวเลข
   - ข้อมูลอากาศจึงต้องมีเพิ่ม: อุณหภูมิเฉลี่ยทั้งปี และต่ำสุดเฉลี่ยของเดือนที่หนาวที่สุด ให้ใช้สถิติสถานีลำปาง 48328 (TMD-LAMPANG-9120: เฉลี่ยทั้งปี 26.7°C, ต่ำสุดเฉลี่ย ธ.ค. 16.2 / ม.ค. 15.6°C, ห้ามใช้ค่าเดือนกันยายน 8.0 ที่ผิดปกติ) แล้วบอกในแอปว่าใช้สถานีลำปางแทนแม่ทะ ถ้าค่าจาก Open-Meteo ต่างจากสถานีมาก ให้จดใน PROGRESS.md
   - ตรวจว่าฝนลำปาง ~1,107 มม./ปี ทำให้ปัจจัยฝนของยางพาราได้ 0 (ช่วงใน crops.json เริ่ม 1,500 มม.) มีเทสต์ใน `tests/crop.test.js` แล้ว
   - ข้าวไวแสงมี `cycleDays` = null และ `harvestApprox` แทน ถ้าโค้ดใหม่ใช้อายุพืช ต้องรองรับ null
5. หน้าแรก: แสดงอุณหภูมิและโอกาสฝนวันนี้ (ถ้ามี) เป็นตัวใหญ่ อ่านง่าย
6. อัปเดตชุดทดสอบให้ครอบคลุมปัจจัยอุณหภูมิและฝน
7. รันตารางกรณีทดสอบใน tests.html อีกครั้ง แล้วจดผลที่เปลี่ยนไปจาก task 03 ลงใน PROGRESS.md
