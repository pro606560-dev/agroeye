# Task 02 — โหลดและตรวจข้อมูล [ใช้ reviewer]

## เป้าหมาย
แอปโหลดไฟล์ใน `data/` ได้ ตรวจว่ารูปแบบถูกต้อง และสรุปได้ว่าข้อมูลส่วนไหนยังขาด

## ต้องทำเสร็จก่อน
01

## ขั้นตอน
1. เขียน `js/data.js` มีฟังก์ชัน `loadCrops()`, `loadSurveyPoints()`, `loadScenarios()` ใช้ `fetch` อ่าน JSON
2. เขียน `validateCrop(crop)` ตรวจว่า
   - มี `id`, `nameTh`, `group`
   - ทุกช่วงตัวเลขเป็น `[min, max]` โดย min ≤ max หรือเป็น null
   - ช่วง optimal อยู่ภายในช่วง tolerable (ถ้ามีทั้งคู่)
   - ทุกค่าที่ไม่ใช่ null มี `source`
   - ค่า texture อยู่ในชุด heavy / medium / light
   - เดือนเป็นเลข 1–12
   - ค่า pH ทุกตัวอยู่ระหว่าง 3–10
   - จำนวนพืชเท่ากับ 12 ชนิด (ถ้าผู้ใช้เพิ่มพืช ให้ผู้ใช้เป็นคนแก้ตัวเลขนี้)
   - ช่อง `source` ทุกช่องที่ไม่ใช่ null ต้องตรงกับรหัสใน `data/SOURCES.md`
3. ถ้าข้อมูลพืชตัวไหนผิดรูปแบบ ให้แอปข้ามพืชนั้น แล้วเขียนคำเตือนใน console ห้ามให้แอปพัง
4. เพิ่มชุดทดสอบใน `tests/data.test.js`: ไฟล์จริงต้องผ่านการตรวจทั้งหมด และข้อมูลผิดที่สร้างขึ้นต้องถูกจับได้
5. เขียนฟังก์ชัน `dataCoverageReport()` ที่สรุปว่าพืชแต่ละชนิดมีปัจจัยกี่ตัวที่ใช้ได้ แล้วแสดงใน `tests.html` เป็นตาราง
6. คัดลอกตารางนี้ลงใน PROGRESS.md
