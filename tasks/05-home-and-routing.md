# Task 05 — หน้าแรก + การเปลี่ยนหน้า

## เป้าหมาย
แอปหน้าเดียวที่สลับหน้าจอด้วย hash และมีหน้าแรกตาม SPEC

## ต้องทำเสร็จก่อน
03, 04

## ขั้นตอน
1. `js/app.js`: router ง่าย ๆ ฟัง `hashchange` แล้วเรียก view ที่ตรงกัน (`#/home`, `#/input`, `#/result`, `#/crop/<id>`, `#/plots`, `#/calendar`, `#/proof`, `#/settings`) ถ้า hash ไม่รู้จัก ให้กลับหน้าแรก
2. `js/storage.js`: ฟังก์ชันอ่าน/เขียน localStorage ที่ครอบด้วย try/catch ทั้งหมด ถ้าใช้ไม่ได้ ให้แอปยังทำงานต่อได้
3. `js/views/home.js`: ปุ่มใหญ่ "ตรวจแปลงใหม่" และ "แปลงของฉัน" + ลิงก์ "ปฏิทินปลูก" กับ "ตั้งค่า" + พื้นที่ว่างไว้แสดงสภาพอากาศ (ใช้ใน task 10)
4. หน้าที่ยังไม่ได้ทำ ให้แสดงข้อความ "หน้านี้กำลังสร้าง" พร้อมปุ่มกลับหน้าแรก
5. ปุ่มย้อนกลับของมือถือต้องใช้ได้ถูกต้อง

## Skill ที่ใช้
- `frontend-design:frontend-design`: ตอนจัดหน้าแรก ให้ใช้ระบบดีไซน์จาก task 04 ห้ามสร้างสีหรือขนาดใหม่

ถ้าไม่มี skill นี้ในรายชื่อ ให้ทำงานต่อตามหลักใน `docs/SPEC.md` แล้วจดใน PROGRESS.md ว่าไม่ได้ใช้
