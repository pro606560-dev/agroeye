# Task 17 — ตรวจรอบสุดท้าย + เตรียมของใส่รายงาน — CHECKPOINT C [ใช้ reviewer]

## เป้าหมาย
แอปพร้อมส่งครู และมีของพร้อมใส่รายงาน IS

## ต้องทำเสร็จก่อน
16

## ขั้นตอน
1. รัน tests.html ให้ผ่านทั้งหมด และตรวจเกณฑ์ "เสร็จทั้งโปรเจกต์" ใน SPEC หัวข้อ 9 ทีละข้อ
2. รัน `design:accessibility-review` กับทุกหน้า แก้ปัญหาระดับร้ายแรงและปานกลาง
3. ตรวจ console ทุกหน้าว่าไม่มี error
4. ตรวจว่าไม่มีไฟล์ไหนโหลดจากภายนอก ยกเว้น Open-Meteo กับ Gemini
5. สร้างโฟลเดอร์ `report/` ใส่ของเหล่านี้สำหรับรายงาน:
   - `report/screenshots/` ภาพหน้าจอทุกหน้า ขนาดมือถือ (ถ้าถ่ายภาพหน้าจอได้)
   - `report/scoring-explained.md` อธิบายสูตรคะแนนภาษาไทยสำหรับนักเรียน ม.4 พร้อมตัวอย่างคำนวณด้วยมือ 1 กรณี
   - `report/proof-results.md` ผลจากหน้าพิสูจน์สมมติฐาน (ตาราง + ข้อสรุป + ข้อจำกัด)
   - `report/data-sources.md` คัดลอกจาก data/SOURCES.md ในรูปแบบบรรณานุกรม
   - `report/user-test-form.md` แบบสอบถามความพึงพอใจ 5 ระดับสำหรับเกษตรกร 5–10 คน (ต่อยอดจากภาคผนวก ข ในรายงาน)
6. อัปเดต README.md: วิธีใช้แอป, ลิงก์ GitHub Pages, ข้อจำกัด
7. ติดแท็ก git `v1.0` แล้ว push
8. อัปเดต PROGRESS.md แล้วหยุด

## Skill ที่ใช้
- `design:accessibility-review`: ตรวจทุกหน้า
- `design:design-critique`: ติภาพหน้าจอทุกหน้า แก้ข้อสำคัญก่อนส่งผู้ใช้
- `design:ux-copy`: อ่านทวนข้อความทั้งแอปรอบสุดท้าย

ถ้าไม่มี skill นี้ในรายชื่อ ให้ทำงานต่อตามหลักใน `docs/SPEC.md` แล้วจดใน PROGRESS.md ว่าไม่ได้ใช้

## รายการให้ผู้ใช้ทดสอบบน OPPO
1. ติดตั้งแอปใหม่จากลิงก์ (ลบไอคอนเก่าก่อน)
2. ทำครบทุกหน้า: ตรวจแปลง → ผล → รายละเอียด → ฟังเสียง → บันทึก → แปลงของฉัน → ปฏิทิน → ตั้งค่า → หน้าพิสูจน์สมมติฐาน
3. โหมดเครื่องบิน: ยังตรวจแปลงได้
4. ใส่ key แล้วได้คำอธิบายจาก AI
5. เปิดไฟล์ใน `report/` แล้วอ่านเข้าใจ
