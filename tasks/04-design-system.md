# Task 04 — ระบบดีไซน์

## เป้าหมาย
มีหน้าตาที่เหมาะกับเกษตรกรสูงอายุ และใช้ซ้ำได้ทุกหน้า

## ต้องทำเสร็จก่อน
01

## ขั้นตอน
1. ใช้ skill `frontend-design` (ถ้ามี) วางแผนดีไซน์ก่อน: สี 4–6 สี, ฟอนต์, หลักการจัดวาง ให้เข้ากับเรื่องเกษตร ดิน และภาคเหนือ แต่ต้องอ่านง่ายเป็นอันดับแรก
2. เขียนแผนดีไซน์ลง PROGRESS.md (สีเป็น hex, ฟอนต์, ขนาดตัวอักษร)
3. `css/style.css`: ตัวแปรสีและขนาดอยู่ใน `:root` ตามหลักใน SPEC หัวข้อ 7 มีคลาสพื้นฐาน เช่น ปุ่มหลัก, ปุ่มรอง, การ์ดตัวเลือกพร้อมรูป, แถบหัวพร้อมปุ่มย้อนกลับ, ข้อความแจ้งเตือน
4. รองรับการปรับขนาดตัวอักษร 3 ระดับด้วยคลาสบน `<html>` (ใช้ใน task 16)
5. ทำรูปหรือไอคอนประเภทดิน 3 แบบเป็น SVG ใน `assets/` (วาดเรียบง่ายเอง ห้ามใช้รูปที่มีลิขสิทธิ์)
6. ทำหน้า `design-preview.html` ที่รวมทุกชิ้นส่วนไว้ดูในหน้าเดียว
7. ตรวจด้วย `design:accessibility-review` (ถ้ามี) อย่างน้อยเรื่องสีตัดกันและขนาดปุ่ม

## Skill ที่ใช้
- `frontend-design:frontend-design`: ก่อนเขียน CSS: วางแผนสี ฟอนต์ การจัดวาง แล้วตรวจแผนกับโจทย์ "เกษตรกรสูงอายุ แม่ทะ"
- `design:accessibility-review`: หลังทำ design-preview.html เสร็จ: ตรวจสีตัดกันและขนาดปุ่ม

ถ้าไม่มี skill นี้ในรายชื่อ ให้ทำงานต่อตามหลักใน `docs/SPEC.md` แล้วจดใน PROGRESS.md ว่าไม่ได้ใช้

## เกณฑ์ผ่าน
- [ ] ตัวอักษรเนื้อหา ≥ 18px, ปุ่มสูง ≥ 56px, สีผ่าน WCAG AA
- [ ] หน้าจอกว้าง 360px ไม่มีแถบเลื่อนแนวนอน
- [ ] ไม่โหลดอะไรจากเน็ต (ดูได้ในแท็บ Network ของเบราว์เซอร์)
