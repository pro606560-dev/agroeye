# Task 06 — หน้ากรอกข้อมูลทีละขั้น

## เป้าหมาย
เกษตรกรกรอกข้อมูลแปลงได้ง่าย หน้าละ 1 คำถาม

## ต้องทำเสร็จก่อน
05

## ขั้นตอน
1. `js/views/input.js` แบ่งเป็นขั้นตาม SPEC หัวข้อ 3 แถว 2 พร้อมแถบบอกว่า "ขั้นที่ 2 จาก 6"
2. ขั้นที่ 1 มี 2 ทาง: ตั้งชื่อแปลงใหม่ หรือเลือกจุดสำรวจจาก `survey-points.json` ถ้าเลือกจุดสำรวจ ให้เติมค่าที่มีให้อัตโนมัติ และข้ามขั้นที่ตอบแล้ว (ค่าที่เป็น null ยังต้องถาม)
3. ขั้นประเภทดิน: การ์ด 3 ใบพร้อมรูปจาก task 04 คำอธิบายสั้น และปุ่ม "วิธีทดสอบดินด้วยมือ" ที่บอกว่า คลึงเป็นเส้นยาวไม่ขาด = ดินเหนียว, เส้นสั้นแตก = ดินร่วน, ปั้นไม่ติดและสากมือ = ดินทราย
4. ขั้น pH: แป้นตัวเลข หรือแถบเลื่อน 3.0–10.0 ทีละ 0.1 แสดงคำว่า ดินเปรี้ยว / ปกติ / ดินเป็นด่าง ข้างตัวเลข มีปุ่มใหญ่ "ไม่ทราบ"
5. ขั้นน้ำขัง: 2 ตัวเลือก "น้ำขังนาน" (poor) / "น้ำไม่ขัง" (good) และ "ไม่ทราบ"
6. ขั้นเดือน: ค่าเริ่มต้นเป็นเดือนนี้ เลือกเปลี่ยนได้
7. ขั้นเพิ่มเติม: แสง (แดดจัด/ร่มรำไร), ความชื้นดิน %, N/P/K มีปุ่ม "ข้าม" ใหญ่
8. ตรวจค่าที่กรอก (เช่น pH นอก 0–14) และแสดงข้อความแนะนำที่สุภาพ
9. กด "ดูผล" แล้วไปหน้าผลลัพธ์พร้อมข้อมูลแปลง (เก็บไว้ในตัวแปรของแอป ยังไม่ต้องบันทึกถาวร)
10. ใช้ `design:ux-copy` (ถ้ามี) ตรวจข้อความทุกขั้น

## Skill ที่ใช้
- `design:ux-copy`: เขียนคำถาม ตัวเลือก ปุ่ม และข้อความแจ้งผิดพลาดทุกขั้น
- `frontend-design:frontend-design`: ตอนจัดการ์ดเลือกดินกับแป้นตัวเลข pH

ถ้าไม่มี skill นี้ในรายชื่อ ให้ทำงานต่อตามหลักใน `docs/SPEC.md` แล้วจดใน PROGRESS.md ว่าไม่ได้ใช้
