# Task 01 — ตั้งค่าโปรเจกต์

## เป้าหมาย
มีโครงโปรเจกต์ที่เปิดดูในเบราว์เซอร์ได้ มี git และมีหน้ารันชุดทดสอบเปล่า ๆ

## ต้องทำเสร็จก่อน
ไม่มี

## ขั้นตอน
0. **ติดตั้งผู้ตรวจและตัวล็อก (ได้รับอนุญาตให้ทำครั้งนี้ครั้งเดียว):** ถ้ายังไม่มีโฟลเดอร์ `.claude/` ให้คัดลอก `_setup/claude/agents/reviewer.md` ไปเป็น `.claude/agents/reviewer.md` และ `_setup/claude/settings.json` ไปเป็น `.claude/settings.json` แบบไม่แก้เนื้อหา แล้วบอกผู้ใช้ให้เริ่มแชตใหม่ 1 ครั้ง เพื่อให้ตัวล็อกและ reviewer เริ่มทำงาน
1. ตรวจว่าในเครื่องมี `git`, `python`, `node` อะไรบ้าง แล้วจดผลลงใน PROGRESS.md
2. ถ้ายังไม่มี git repo ให้รัน `git init` และตั้ง branch หลักชื่อ `main`
3. สร้าง `.gitignore` (กันไฟล์ระบบ เช่น `Thumbs.db`, `.DS_Store`, โฟลเดอร์ `node_modules/` และไฟล์ที่ชื่อมีคำว่า `secret` หรือ `.env`)
4. สร้างโครงโฟลเดอร์ตาม `tasks/README.md` (ยังไม่ต้องมีโค้ดจริง)
5. สร้าง `index.html` ที่มีแค่หัวข้อ "AgroEye" กับข้อความ "กำลังสร้าง" ภาษาไทย ตั้ง `lang="th"`, `meta viewport`, `charset=utf-8`
6. สร้าง `tests.html` เป็นตัวรันชุดทดสอบเล็ก ๆ ที่เขียนเอง (ไม่ต้องใช้ไลบรารี) โหลดไฟล์ใน `tests/` แล้วแสดงจำนวนข้อที่ผ่าน/ไม่ผ่าน เป็นสีเขียว/แดง
7. ใส่ชุดทดสอบตัวอย่าง 1 ข้อที่ผ่านเสมอ เพื่อพิสูจน์ว่าตัวรันใช้ได้
8. เปิดเซิร์ฟเวอร์ทดสอบตามวิธีใน CLAUDE.md แล้วเปิดทั้ง `index.html` และ `tests.html` ดู
9. เขียน `README.md` สั้น ๆ ภาษาไทย: แอปนี้คืออะไร และเปิดทดสอบอย่างไร

## Skill ที่ใช้
ไม่ต้องใช้ skill ใน task นี้ (เป็นงานโค้ดและข้อมูล ทำตามขั้นตอนได้เลย)

## เกณฑ์ผ่าน
- [ ] มี `.claude/agents/reviewer.md` และ `.claude/settings.json` เนื้อหาตรงกับใน `_setup/claude/`
- [ ] `http://localhost:8000/` แสดงคำว่า AgroEye ภาษาไทยไม่เพี้ยน
- [ ] `http://localhost:8000/tests.html` แสดง "ผ่าน 1 / 1"
- [ ] `git log` มี commit แรก
- [ ] ไม่มีไฟล์ที่ควรซ่อนหลุดเข้า git

## หมายเหตุ
- ไฟล์ใน `data/` มีอยู่แล้ว ห้ามสร้างทับ
- ถ้าเครื่องไม่มีทั้ง Python และ Node ให้หยุด แล้วบอกผู้ใช้ว่าควรติดตั้ง Python (แนะนำ) ทีละขั้น
