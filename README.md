# AgroEye

เว็บแอปแนะนำพืชสำหรับเกษตรกรสูงอายุในอำเภอแม่ทะ จังหวัดลำปาง กรอกข้อมูลแปลงแล้วแอปจะแนะนำพืช 3 อันดับพร้อมเหตุผล
เป็นโครงงาน IS ชั้น ม.4 รายละเอียดอยู่ใน `docs/SPEC.md`

**เปิดแอป:** https://pro606560-dev.github.io/agroeye/ (เวอร์ชัน 1.0)

## วิธีใช้แอป
1. เปิดลิงก์ด้านบนด้วย Chrome บนมือถือ เปิดแอปตอนมีเน็ต 1 ครั้ง แล้วจะใช้ตอนไม่มีเน็ตได้ ถ้าอยากมีไอคอนบนหน้าจอ ให้กดเมนู ⋮ ของ Chrome → "เพิ่มลงในหน้าจอหลัก" หรือ "ติดตั้งแอป"
2. กด **ตรวจแปลงใหม่** แล้วตอบทีละหน้า: ชื่อแปลง → ทดสอบเนื้อดิน 3 วิธี → เลือกประเภทดิน → ค่า pH (กด "ไม่ทราบ" ได้) → น้ำขังไหม → เดือนที่อยากปลูก → ข้อมูลเพิ่มเติม (ข้ามได้)
3. หน้าผลแสดงพืช 3 อันดับ คะแนน เหตุผล และความมั่นใจ กด **ดูวิธีปลูก** เพื่อดูวิธีดูแล ความเสี่ยง และแหล่งข้อมูล
4. กด **บันทึกแปลงนี้** แล้วดูย้อนหลังได้ที่ **แปลงของฉัน**
5. **ปฏิทินปลูก** บอกว่าแต่ละเดือนเริ่มปลูกพืชอะไรได้
6. **ตั้งค่า**: ขนาดตัวอักษร, เปิด/ปิดเสียงอ่าน, ใส่รหัส AI (Gemini) เพื่อให้มีคำอธิบายสั้น ๆ ในหน้าวิธีปลูก (ไม่ใส่ก็ใช้แอปได้ครบ), ล้างประวัติ, หน้าพิสูจน์สมมติฐาน (สำหรับครู)

## ข้อจำกัด
- แนะนำได้เฉพาะพืช 12 ชนิดใน `data/crops.json` และใช้ข้อมูลอากาศของอำเภอแม่ทะ / สถานีลำปางเท่านั้น
- พืชบางชนิดยังขาดข้อมูลบางเรื่อง (เช่น เดือนปลูกของ 7 ชนิด) แอปจะไม่นับเรื่องนั้นและบอกว่า "ยังไม่มีข้อมูล" ดูความมั่นใจประกอบเสมอ
- ค่าความต้องการของพืชบางส่วนเป็นค่าทั่วโลก (FAO ECOCROP) ไม่ได้วัดในประเทศไทย
- การทดสอบเนื้อดินด้วยมือเป็นค่าประมาณ ถ้าไม่แน่ใจควรถามหมอดินอาสาหรือสถานีพัฒนาที่ดินลำปาง
- ความชื้นดินและ N/P/K เก็บไว้ในประวัติ แต่ยังไม่ใช้คิดคะแนน
- คำอธิบายจาก AI ต้องมีเน็ตและรหัส และอาจผิดพลาดได้ AI ไม่ได้เป็นคนเลือกพืช
- ปุ่มฟังเสียงมีเฉพาะเครื่องที่มีเสียงภาษาไทย
- ข้อมูลจริงที่ทีมวัดเองยังมีแค่ 1 แปลง ผลพิสูจน์ส่วนใหญ่ใช้ข้อมูลชุดดินของกรมพัฒนาที่ดิน
- คำแนะนำไม่ได้ทำนายผลผลิตหรือราคา ควรปรึกษาเกษตรอำเภอก่อนลงทุน

## ของสำหรับรายงาน
อยู่ในโฟลเดอร์ `report/`: ภาพหน้าจอ, อธิบายสูตรคะแนน, ผลพิสูจน์สมมติฐาน, บรรณานุกรม, แบบสอบถามความพึงพอใจ

## เปิดทดสอบบนคอม
1. เปิด PowerShell ในโฟลเดอร์นี้ แล้วรัน `python -m http.server 8000`
2. เปิด `http://localhost:8000/` เพื่อดูแอป
3. เปิด `http://localhost:8000/tests.html` เพื่อดูผลชุดทดสอบ ต้องขึ้นสีเขียว
